# L1 Help Article: Computer Setup Not Finishing

Version: v 1.0  
Date: 11/08/2026  
Status: Draft

If your computer setup does not finish and you see a message saying the computer is already set up, your files and company data are safe. This can happen when old setup information is still linked to the computer, and setup cannot continue until the help desk clears it.

## What you can do now
1. Save any open work if possible.
2. Restart your computer once.
3. Try setup again after restart.
4. If the same message appears, stop and wait.
5. Contact the IT help desk and share the details listed below.

## What not to do
- Do not keep trying setup again and again.
- Do not remove work sign-in settings yourself.
- Do not erase and set up the computer again unless the IT help desk asks you to.

## Details to include in your help request
- Your computer name (for example: DESKTOP-FB099)
- Your work sign-in name
- The exact message shown on screen
- The error number if shown (for example: 0x80180014)
- The date and time when the issue happened
- A photo of the error message on screen

Contact the IT help desk if setup still fails after one restart, or if the same error message appears again.
