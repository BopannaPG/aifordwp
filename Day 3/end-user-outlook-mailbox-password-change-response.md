Thank you for reaching out, and I’m sorry you’re having trouble accessing your Outlook mailbox after changing your password this morning.

The most likely cause is that Outlook is still using your previous saved credentials, so it cannot authenticate with the mailbox using the new password yet.

Please try the following steps:

1. Close Outlook fully (including from the system tray), then reopen it and sign in with your new password when prompted.
2. Disconnect and reconnect your account credentials:
   - Open Windows Credential Manager
   - Remove stored Microsoft/Office/Outlook credentials
   - Restart Outlook and enter your new password
3. Restart your computer, then confirm you can sign in to Microsoft 365 on the web (outlook.office.com) using the new password before testing the desktop Outlook app again.

- Any exact error message or screenshot
- Whether Outlook on the web works
- Your device name and Windows version
